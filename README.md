# Gebäudetechnik Tissen – Website-Entwurf

Entwurf einer neuen, schlanken Website für [Gebäudetechnik Tissen](https://gebaeudetechnik-tissen.de/) aus Bad Oeynhausen. Herzstück: der Anfrage-Regler, der Kundenanfragen direkt als vorformulierte WhatsApp-Nachricht öffnet.

- Konzept, SEO-Plan und offene Punkte liegen intern (nicht im öffentlichen Repo).
- Lokal ansehen: `python3 -m http.server 4180`, dann http://localhost:4180
- Tests: `npm test`

Der Entwurf ist bewusst auf `noindex` gestellt, damit er der echten Domain keine Konkurrenz macht.
